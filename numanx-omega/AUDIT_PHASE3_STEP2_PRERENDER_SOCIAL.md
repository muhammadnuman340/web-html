## 3. PRERENDER COUNT DISCREPANCY RESOLVED

The Phase 3 / Step 1 audit identified a count discrepancy between the 13 `index.html` files found on disk and the 12 prerendered routes reported. An exhaustive disk inspection revealed the exact cause:

- **Existing Prerendered URL Count:** 12 URLs (`/about`, `/blog`, `/convert/area`, `/convert/data`, `/convert/energy`, `/convert/length`, `/convert/mass`, `/convert/pressure`, `/convert/speed`, `/convert/temp`, `/convert/time`, `/convert/volume`).
- **Existing `index.html` Count in `dist/`:** 13 files.
- **Explanation of Difference:** `dist/index.html` was the empty SPA root shell generated by `vite build` (`<div id="root"></div>`). The previous `scripts/prerender-seo.mjs` only generated 12 subdirectories, leaving the root `dist/index.html` completely un-prerendered without meaningful initial HTML.
- **Final Prerender Count in Step 2:** **146 HTML files** (1 `dist/index.html` + 145 subdirectories matching every single sitemap route).
- **Final Indexable HTML Coverage:** **146 / 146 (100.0%)**.
